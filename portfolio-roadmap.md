# Portfolio Development Roadmap

This roadmap shows how I plan to build on my current cyber security study and projects. Items marked **Planned** are future work and are not presented as completed experience.

## Current portfolio evidence

- Completed NCFE Level 2 Certificate in the Principles of Cyber Security.
- NCFE Level 3 Certificate in Cyber Security Practices — in progress.
- Online-shop STRIDE threat model, created as a learning exercise.
- Level 3 study notes covering foundations, security testing approaches, vulnerability scanning, and public incident case studies.

## Planned projects

### 1. Example risk register — Planned

Create a risk register for a fictional small organisation or system. It will record example assets, threats, vulnerabilities, likelihood, impact, risk rating, proposed treatment, and residual risk. The scenario and ratings will be clearly identified as illustrative.

### 2. Security controls review — Planned

Review a fictional system against selected security control themes, such as access management, patching, logging, backups, and data protection. Explain what evidence would be needed to assess each control and what gaps or follow-up actions might arise. This will be a learning exercise, not a formal audit or certification assessment.

### 3. Vulnerability assessment report — Planned

Document an assessment carried out only in an authorised learning lab or coursework scenario. The report will state the scope, method, findings, severity rationale, suggested remediation, and limitations. No unauthorised systems will be tested.

### 4. Incident response case study — Planned

Analyse a public cyber incident or a fictional exercise. Summarise the incident, likely impacts, response priorities, lessons learned, and practical defensive improvements. This will be clearly presented as study and analysis, not participation in a real incident response.

## How I will present each project

Each project will include:

- **Purpose and scenario**
- **Scope and assumptions**
- **Method or framework used**
- **Findings and reasoning**
- **Recommended actions**
- **Limitations and learning points**
- **Status**, such as planned, in progress, or completed

I will only mark work as complete after I have carried it out. Coursework and lab work will be labelled accurately, and I will not include credentials, personal data, or information from systems I do not have permission to assess.
